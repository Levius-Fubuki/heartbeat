# Onboarding 脚本(两段式)

首次启动、检测到用户档案(B 档案)为空时触发。由当前选中的人格带队,用其语气进行。
是同一聊天 UI 的特殊模式;完成后把抽取到的结构化字段写入 L2 的 B 档案,转入正常运行。

> **实现说明(2026-07-23)**:Stage 1(选人格)完成后**不自动接访谈**——访谈改为**手动入口**:
> 主界面状态栏的「认识我」(首次)/「重新认识」(已访谈过)按钮触发。老用户不被打扰,想体验/
> 补全档案时随时点。访谈由选中人格 LLM 自主带队(日常非正式风),每轮实时增量抽取写进 L2;
> 四路自然收尾:静默 60s / 轮数上限(默认 8)/ 用户点「跳过访谈」/ 切人格中断。访谈期间屏蔽心跳打扰。

## Stage 1 · 选人格

中性地开场,再列出 5 个选项:

> 嗨,我在这里啦。在正式开始之前——你想让我是哪一种存在呢?
>
> ① **Zorya** — 安静的星,话少,只在值得时开口
> ② **Vesna** — 像初春,对一切充满好奇
> ③ **Rada** — 开朗热烈,把你当最重要的人
> ④ **Yara** — 嘴利的损友,会吐槽也懂你
> ⑤ **Mira** — 温和的守护者,稳稳陪着

## Stage 2 · 用户访谈(由选中人格带队,日常非正式风)

每次 1–2 个问题,跟着用户走、对答案有反应,也让宠物分享一点自己(互相了解)。
总共几分钟、6–10 轮,可暂停可续,任何问题都能跳过。

**示例(用户选了 Vesna):**

> Vesna:初春诶,好棒!那——你平时都在电脑前忙些什么呀?工作还是学习?
> 用户:写代码,顺便做点自己的小项目。
> Vesna:哦!自己折腾小项目最有趣了🍃 都做些什么方向的呀?
> 用户:AI 相关的。
> Vesna:哇——那我要是哪天能帮上忙就好啦。对了,你一般在什么时段敲代码?有没有特别不想被打扰的时间?
> …(继续:爱好、作息、聊天偏好、免打扰窗口、一个彩蛋)

## 要了解的字段(LLM 从对话实时抽取,不硬解析)

```yaml
identity: { role, fields }            # 工作/学习/方向
interests: [ ... ]                     # 爱好(喂给心跳互动情境)
schedule: { focus_hours, dnd_windows } # 作息与免打扰
chat_pref: { verbosity, emoji_ok }     # 多聊还是少聊
fun_fact: "..."                        # 一个小彩蛋
```

抽取后写入 L2 的 B 档案,之后每次注入 system prompt。onboarding 只是种子,
日常互动会持续丰富它(后续接 L3 情景日志 / L4 模式沉淀)。
